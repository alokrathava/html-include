Assets and Data

partials/promo-card.html lives in a different directory than this page, but its <img> uses a plain relative path (assets/logo.svg). That path resolves against this document's URL, not against the partial's file location — so it works because assets/ sits next to index.html, not next to the partial.

The partial also embeds a <script type="application/json"> data block alongside a normal executable <script>. With allow-scripts, only the executable one is recreated and run; the JSON block is left in the DOM untouched and just read as data.
