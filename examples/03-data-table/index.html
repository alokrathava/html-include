Data Table

A raw <html-include> element cannot go inside a <table> outside of a cell: the HTML parser doesn't recognize it as valid table content and "foster-parents" it out — it gets moved to just before the table, and any rows it would have inserted end up as siblings of the table instead of inside <tbody>.

The fix here is attribute-based hydration: put data-include directly on the real <tbody> and let a small script fetch and inject into it. No foster parenting, because no custom element is ever placed inside the table.
